# 🎨 Vinz — BSIT 3rd-Year UI/UX Designer Portfolio & Presentation

A modern, interactive personal portfolio and UX case study showcase designed for a **3rd-Year Bachelor of Science in Information Technology (BSIT)** student specializing in **UI/UX Design, Product Design, and Human-Computer Interaction (HCI)**.

---

## 🌟 Key Features & Highlights

1. **🌊 Electric Blue Palette & Interactive Dark / Light Mode**
   - Electric & Sapphire Blue design aesthetic (`#2563eb`, `#38bdf8`, `#06b6d4`).
   - One-click **Dark / Light Mode Toggle** in the navigation bar with saved `localStorage` preference.

2. **🚀 Hero Section with UI/UX Student Focus**
   - Dynamic typing roles (*BSIT 3rd-Year UI/UX Student*, *Product & Interaction Designer*, *Design Systems Specialist*).
   - Live availability badge: `🟢 Open for UI/UX Internship / OJT & Capstone Design`.
   - Floating Figma & Design System badges, 3D avatar with tablet, and design metrics.

3. **📐 5-Step Double Diamond Design Process ("How I Design")**
   - Interactive 5-phase breakdown: *Discover & Empathize*, *Define & Structure*, *Wireframe & Lo-Fi*, *Visual UI & Design System*, *Prototype & Usability Testing*.
   - Includes real-world UX deliverables, activities, and tools (*FigJam*, *Miro*, *Figma*, *Maze*).

4. **🛠️ UI/UX & Interaction Skills Matrix**
   - Categorized tabs: *Design Tools (Figma, FigJam, Adobe XD)*, *UX Research (Personas, Journey Mapping, Usability Testing)*, *UI & Visual Craft (Design Systems, Auto-Layout, Tokens)*, *UI Prototyping (Tailwind CSS, Micro-Animations)*, and *HCI & Usability Laws (Nielsen's 10 Heuristics, WCAG 2.1 AA, Fitts's Law)*.

5. **📂 Featured UI/UX Case Studies with Walkthrough Modals**
   - **StudyPulse** — Student Habit & Productivity App (Mobile UX Case Study)
   - **Lumina Health** — Telehealth Consultation Portal (Web App Redesign & Accessibility)
   - **CampusBite** — University Cafeteria Pre-Ordering App (HCI Course Project)
   - **Aurora UI Kit** — Scalable Figma Design System & Component Tokens
   - Interactive **Case Study Modal** detailing Problem Statements, UX Solutions, User Personas, Research Insights, and Figma Links.

6. **🧪 Interactive UI/UX Component Lab (Classroom Showstopper!)**
   - **Tactile Micro-Interactions Sandbox**: Test spring bounce buttons, persistent heart/bookmark state toggles, and segmented pill controls.
   - **Live WCAG 2.1 Contrast Ratio Calculator**: Click background and text swatches to compute real-time mathematical contrast scores with instant Pass/Fail feedback.
   - **Classroom A/B Usability Experiment Simulator**: Live interactive poll demonstrating visual affordance and conversion heuristics.

7. **📄 Interactive UI/UX Resume / CV & PDF Printer**
   - Pop-up designer CV with college HCI background, coursework, honors, and one-click `Print / Save as PDF`.

8. **📫 Working Contact Section & Feedback**
   - One-click copy email button with animated checkmark and toast.
   - Interactive feedback form with confetti celebration.

---

## 🛠️ Tech & Design Stack

- **Design Software**: Figma (Auto-Layout, Component Props, Smart Animate), FigJam, Miro
- **Frontend Prototyping**: Vue 3 (Composition API `<script setup>`)
- **Styling**: Tailwind CSS v4 (Light & Dark Theme Tokens, Custom Designer Grid)
- **Icons**: Lucide Icons (`lucide-vue-next`)
- **Effects**: `canvas-confetti`
- **Typography**: Outfit, Plus Jakarta Sans, Fira Code

---

## 🚀 How to Run Locally

```bash
# 1. Open the project folder
cd vinz-portfolio

# 2. Run the Vite development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

## 🎯 Classroom Presentation Guide

1. **Theme Switcher**: Toggle between **Dark Mode** and **Light Mode** in the navbar to show your mastery of multi-theme design systems.
2. **Design Process**: Walk the class through the **5-Step Double Diamond Process** to demonstrate how you approach user research and wireframing systematically.
3. **Case Studies**: Click **"Read Case Study"** on *StudyPulse* or *Lumina Health* to present user personas, problem-solution breakdowns, and design decisions.
4. **UX Lab**: Switch between the **Micro-Interactions**, **WCAG Contrast Checker**, and **A/B Test Simulator** for a fun, interactive live audience demonstration!
5. **Resume**: Open the **"UX Resume"** modal to present your structured academic profile.
